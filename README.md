RetailMart Sales & Inventory Analytics

Project Overview:
An interactive Power BI dashboard developed to analyze retail sales, profitability, product performance, inventory, and returns using a sample retail dataset.

Tools & Technologies:
Power BI
DAX
Power Query
Microsoft Excel
Data Modeling
Data Visualization

Key Features:
KPI cards for sales, profit, orders, and profit margin
Monthly sales trend analysis
Category and regional performance analysis
Top 10 product analysis
Inventory value and reorder analysis
Returns analysis
Interactive slicers and filters

Skills Demonstrated:
Data cleaning and transformation
Relational data modeling
DAX measure creation
Interactive dashboard development
Business data analysis.

Project Type:
Portfolio project using a sample retail dataset.
